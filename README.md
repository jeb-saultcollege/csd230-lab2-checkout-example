# CSD230 Lab 2 Checkout Example

This is a sanitized teaching example for studying a Spring MVC bookstore checkout flow. The `main` branch is the baseline; the open pull request shows annotated instructor corrections for order creation, checkout routing, and confirmation.

Screenshots and submission-specific documentation were omitted. Database credentials are intentionally not included. Configure `DB_USERNAME`, `DB_PASSWORD`, and `MYSQL_ROOT_PASSWORD` locally before starting MySQL; keep any `.env` file untracked.

The example changes have not been independently built or runtime-tested here. Treat the pull request as a code walkthrough, not a verified release.
